# 개인 심화 영어 파일럿 — 한국어 원문·영어 대조표

- **고정 가상 입력:** 레드·블루·화이트 / 레드 삼각형·블루 마름모·화이트 네모
- **한국어 기준:** 역할 명칭 정리 작업본의 동일 입력·동일 해석 순서
- **목적:** 중국어 파일럿과 같은 한국어 원문을 바탕으로 의미·문체·역할 용어를 검토하는 영어 샘플
- **제외:** 고객 데이터, 로그인, 결제, 쿠폰, DB, 자동 이메일, 기존 private PDF, Production

## 문체 기준

1. 심리 해석은 `may`, `can`, `might`, `often`을 필요한 자리에 한 번만 둡니다.
2. `You are...`, `You will...`, `This will...`처럼 성격·행동·효과를 확정하지 않습니다.
3. 행동 제안은 `You might...`, `You could...`, `Try...`처럼 선택 가능한 제안으로 씁니다.
4. `Recovery Direction`은 역할명에, `ease`, `rest`, `readjust`, `regain balance`는 일상 실천 문맥에 구분해 사용합니다.
5. `HUSIM COLOR`는 브랜드 표기로 유지합니다. 서비스 설명에는 과도한 자격 암시를 피한 **1:1 Colour Psychology Conversation**을 사용합니다.
6. 영국식 `colour`을 사용합니다. 미국 시장을 우선하면 UI·PDF·이메일 전 범위에서 `color`로 한 번에 바꿉니다.
