# 역할 용어 감사 및 중국어 v3 기반 번역 가이드

> **검수 기준일:** 2026-10-12
> **범위:** 운영 한국어 소스의 표기·데이터 역할 감사, 중국어/영어 고정 가상 샘플
> **제외:** 한국어 운영 화면·고객 결과·스냅샷·PDF·자동 이메일·결제·DB 변경 및 Production 배포

## 1. 결론

- **3번째 심리카드의 데이터상 역할은 ‘회복 방향’**입니다. `cardData.ts`의 역할 정의는 `recoveryDirection`이며, “앞으로 필요한 에너지·구체적 행동 제안”으로 명시되어 있습니다.
- 반면 운영 한국어 화면·PDF에는 3번째 심리카드를 **‘다음 방향’**, **‘회복 방향’**, **‘미래·회복·희망 에너지’**로 혼용하는 곳이 있습니다. 이 표기는 차후 한 기준으로 정리할 대상입니다.
- 운영 한국어에서 3번째 **선택 컬러**는 현재 `회복방향`으로 표시됩니다. 그러나 요청 기준의 3번째 컬러는 `보완컬러`입니다.
- 운영에는 이미 입력 후 계산되어 제안되는 별도 **‘보완 컬러’**가 있습니다. 따라서 향후 3번째 선택 컬러를 `보완컬러`로 바꿀 경우, 현재의 추천 결과와 혼동되지 않도록 추천 결과는 **`추천 보완 컬러`**처럼 구분하는 설계가 필요합니다.

### 역할 정의의 분리

| 구분 | 향후 사용자용 한국어 기준안 | 역할 | 중국어 간체 | 영어 파일럿 |
|---|---|---|---|---|
| 컬러 1 | 주기질 | 비교적 지속적인 기본 성향 | 主要心理特征 | Primary Disposition |
| 컬러 2 | 보조기질 | 기본 성향을 보완해 함께 드러나는 성향 | 辅助心理特征 | Supporting Disposition |
| 컬러 3 | 보완컬러 | 현재 리듬의 균형을 돕는 **선택 컬러** | 调和色 | Complementary Colour |
| 계산형 추천 컬러 | 추천 보완 컬러 | 선택 결과를 바탕으로 추가 제안되는 컬러 | 推荐调和色 | Suggested Complementary Colours |
| 카드 1 | 무의식 | 깊은 내면의 욕구·반복 패턴 | 潜意识 | Unconscious |
| 카드 2 | 현재흐름 | 현재 상태와 현실 반응 | 当前状态 | Current State |
| 카드 3 | 회복방향 | 상태를 회복·조정하는 데 필요한 에너지와 실천 | 恢复方向 | Recovery Direction |

> 위 표의 `컬러 3 = 보완컬러`와 `추천 보완 컬러`는 **향후 현지화·한국어 통일 시의 제안 기준**입니다. 현재 운영 한국어 원문은 아직 바꾸지 않았습니다.

## 3. 중국어 v3에서 이어받은 문체 원칙

1. **심리코칭이지 진단이 아니다.** 경향 문단에는 `可能`·`往往`·`更倾向于`를 필요한 지점에 한 번만 사용한다.
2. 한 문단마다 유보 표현을 겹치지 않는다. 행동 제안에는 `不妨`·`可以尝试…`·`可以先…`을 자연스럽게 사용한다.
3. `恢复`는 카드의 **恢复方向**과 회복·균형이라는 개념에 사용하고, 일상 행동에는 필요에 따라 `调整状态`·`放松`·`休息`·`找回平衡`을 사용한다.
4. `潜意识`(무의식), `当前状态`(현재 상태), `恢复方向`(회복 방향)은 같은 뜻으로 합치지 않는다.
5. `调和色`은 선택 컬러의 역할명, `推荐调和色`은 계산형 추천 컬러로 구분한다.
6. 컬러·도형 원문, 강점, 지칠 때 특징, 세 컬러 통합, 카드 순서, 사회 역할, 오행·일상 실천을 삭제하거나 새 근거 없이 추가하지 않는다.

## 4. 최종 중국어 샘플 핵심 대조

| 한국어 원문 | 초기/기존 중국어 | 현재 파일럿 기준 중국어 | 판단 |
|---|---|---|---|
| 할 일이 생기면 먼저 방향을 정하고 말을 충분히 듣고 판단하는 편입니다. | 再了解相关信息，作出判断 | 面对需要处理的事情，你往往会先明确方向，充分听取对方的想法后，再作判断。 | ‘상대의 말을 듣는’ 뜻을 복원 |
| 일의 우선순위를 빠르게 잡습니다. | 你能较快厘清工作的轻重缓急 | 你往往能较快理清事情的轻重缓急 | 문서식 표현을 줄이고 경향 유지 |
| 서로의 생각을 분명히 나누며 방향을 맞추고 싶어 합니다. | 一起把方向协调好 | 一起找到双方都能接受的方向 | 관계 문맥에서 자연화 |

| 별도 계산형 보완 컬러 | 调和色 | **推荐调和色** | 선택 3번째 컬러와의 혼동 방지 |
| 현재 흐름에서 과해지기 쉬운 결을 누그러뜨리고, 회복 방향을 돕는 컬러입니다. | 번역투의 교정·치료형 설명 | 这些颜色可作为日常自我调节的参考，帮助你放松身心、找回平衡，而不是要求你改变自己。 | 자기 조절 참고라는 코칭 뜻 유지 |

## 5. 영어 파일럿 적용 기준

- 영문도 같은 고정 한국어 원문과 입력값을 사용합니다.
- `Primary Disposition / Supporting Disposition / Complementary Colour`과 `Unconscious / Current State / Recovery Direction`을 분리했습니다.
- `may`, `often`, `can`, `might`를 문단마다 과도하게 반복하지 않으면서, 고정된 성격 판정이나 효과 보장은 피했습니다.
- 영국식 표기인 `Colour`을 브랜드 문서·제목에 사용했습니다. 앱 스토어 국가 전략에서 미국 영어를 별도 우선한다면 `Color`로 일괄 전환할 수 있으나, 의미와 문체는 바뀌지 않습니다.

## 6. 구현 전 확정이 필요한 결정

1. 한국어에서도 실제로 3번째 선택 컬러를 `보완컬러`로 바꿀지, 현재 `회복방향`을 유지할지.
2. 바꾼다면 계산형 현재 ‘보완 컬러’를 `추천 보완 컬러`로 구분할지.
3. 카드 3번째는 모든 화면·PDF·관계 리포트·이메일에서 `회복방향`으로 통일할지.
4. 위 결정 후 결과 생성 시 locale과 copyVersion을 스냅샷/PDF/outbox metadata에 저장할지. 기존 한국어 immutable 결과는 변환·재생성·재발송하지 않습니다.

## 7. 파일럿 범위와 보호 장치

- 중국어·영어 파일럿은 **고정 가상 데이터**만 사용합니다.
- 로그인, 고객 데이터, 결제, 쿠폰, DB, 자동 이메일, private PDF, 기존 스냅샷을 읽거나 쓰지 않습니다.
- 본 문서는 운영 원본을 수정하는 명세가 아니라, 전체 구현 전 사용자가 용어·문체를 승인하기 위한 검수 가이드입니다.
