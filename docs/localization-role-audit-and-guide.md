# 역할 용어 감사 및 중국어·영어 파일럿 번역 가이드

> **기준일:** 2026-10-12
>
> **대상:** 한국어 역할 명칭 정리 작업본 및 고정 가상 데이터 기반 중국어·영어 파일럿
> **보호 범위:** 기존 고객 결과·immutable snapshot·보관 PDF·주문·outbox 이메일은 변경·재생성·재발송하지 않는다.

## 1. 확정 역할 체계

| 구분 | 한국어 | 중국어 간체 | 영어 | 의미 |
|---|---|---|---|---|
| 선택 컬러 1 | **주기질** | **主要心理特征** | **Primary Disposition** | 비교적 지속적으로 드러나는 기본 성향 |
| 선택 컬러 2 | **보조기질** | **辅助心理特征** | **Supporting Disposition** | 주기질과 함께 드러나는 보조 성향 |
| 선택 컬러 3 | **회복방향** | **恢复方向** | **Recovery Direction** | 선택한 세 번째 컬러가 가리키는 균형·회복의 방향 |
| 심리카드 1 | **무의식** | **潜意识** | **Unconscious** | 내면의 욕구·반복 패턴을 살피는 위치 |
| 심리카드 2 | **현재흐름** | **当前状态** | **Current State** | 지금의 상태와 현실 반응을 살피는 위치 |
| 심리카드 3 | **회복방향** | **恢复方向** | **Recovery Direction** | 상태를 회복·조정하는 데 참고할 에너지와 실천 |
| 계산형 별도 추천 색 | **추천 보완컬러** | **推荐调和色** | **Suggested Balancing Colours** | 선택 결과를 바탕으로 추가 제안되는 색. 선택한 3번째 컬러와 별도 |

> **중요:** 세 번째 선택 컬러와 세 번째 심리카드는 모두 `회복방향`이지만, 전자는 **컬러 선택의 역할**, 후자는 **심리카드 위치의 역할**입니다. 별도로 계산해 추천하는 색만 `추천 보완컬러`로 표기합니다. `보완컬러`는 세 번째 선택 컬러의 이름으로 사용하지 않습니다.

## 2. 한국어 작업본 감사 결과

| 범위 | 확인된 표기 | 정리 결과 |
|---|---|---|
| 무료 결과 | 주기질 / 보조기질 / 회복방향, 추천 보완컬러 | 선택 컬러 3개와 계산형 추천 색을 분리 |
| 개인 심화 화면·PDF payload·PDF | 주기질 / 보조기질 / 회복방향, 무의식 / 현재흐름 / 회복방향 | `나의 또 다른 성향`, `다음 방향`, 띄어 쓴 역할 제목을 사용자용 역할명에서 제거 |
| 관계 결과·초대 snapshot 생성·부부/부모자녀 PDF | 같은 선택 컬러·심리카드 역할명, 추천 보완컬러 | 새로 생성되는 결과·PDF·첨부 PDF가 같은 payload 역할명을 사용 |
| 공개 샘플 생성기 | 같은 역할명 | 기존 공개 파일을 덮어쓰지 않고, 앞으로 새로 만드는 샘플의 역할명만 정렬 |

이 문서가 작성된 시점의 한국어 변경은 분리된 검증 작업본에만 있으며, 운영 반영 여부는 별도 배포 검증 결과로 판단합니다.

## 3. 중국어 간체 작성 규칙

1. 심리코칭은 진단이 아니다. 경향 문단에는 `可能`·`往往`·`更倾向于`를 필요한 지점에 한 번만 사용한다.
2. 행동 제안에는 `不妨`·`可以先…`·`可以尝试…`을 사용하고, 결과나 효과를 보장하지 않는다.
3. `潜意识`·`当前状态`·`恢复方向`은 서로 다른 카드 위치의 개념으로 합치지 않는다.
4. `恢复方向`은 세 번째 **선택 컬러**와 세 번째 **심리카드**에 공통으로 쓰되, 화면의 위치·카드 번호를 함께 보여 사용자가 구분할 수 있게 한다.
5. 계산형 추천 색은 반드시 `推荐调和色`으로 표기한다. `调和色`만으로 쓰지 않는다.
6. `恢复`는 역할명·회복의 개념에, 일상 행동에는 문맥에 따라 `调整状态`·`放松`·`休息`·`找回平衡`을 쓴다.
7. `HUSIM COLOR`는 브랜드 표기로 유지한다. `休心色彩`은 브랜드의 확정 번역으로 가정하지 않는다.

### 중국어 핵심 대조

| 한국어 | 권장 중국어 | 판단 |
|---|---|---|
| 할 일이 생기면 먼저 방향을 정하고 말을 충분히 듣고 판단하는 편입니다. | 面对需要处理的事情，你往往会先明确方向，充分听取对方的想法后，再作判断。 | ‘상대의 말을 충분히 듣는’ 뜻을 보존 |
| 일의 우선순위를 빠르게 잡습니다. | 你往往能较快理清事情的轻重缓急。 | `厘清` 같은 문서체를 일상어로 조정 |
| 서로의 생각을 분명히 나누며 방향을 맞추고 싶어 합니다. | 你可能更希望把彼此的想法说清楚，一起找到双方都能接受的方向。 | 관계에서의 공동 조율을 자연화 |
| 현재 흐름에서 과해지기 쉬운 결을 누그러뜨리고, 회복 방향을 돕는 컬러입니다. | 这些颜色可作为日常自我调节的参考，帮助你放松身心、找回平衡，而不是要求你改变自己。 | 추천 색을 교정·치료가 아닌 일상 참고로 설명 |

## 4. 영어 작성 규칙과 대안 선정

| 한국어 개념 | 채택 영어 | 검토한 대안 | 채택 이유 |
|---|---|---|---|
| 주기질 | **Primary Disposition** | Primary Trait | 고정 성격 유형보다 ‘경향’으로 읽힘 |
| 보조기질 | **Supporting Disposition** | Secondary Trait | 서열·성격 단정의 인상을 줄임 |
| 회복방향 | **Recovery Direction** | Next Direction | 카드 데이터의 회복·실천 의미를 보존 |
| 추천 보완컬러 | **Suggested Balancing Colours** | Suggested Complementary Colours | `complementary colour`가 색채 이론의 보색으로 오해될 수 있어, 일상 균형을 돕는 추천이라는 기능을 더 명확히 함 |
| 역할 유형 | **Making Sense of Information** | Information Sense-Making & Judgment Profile | 긴 검사 유형명보다 일반 사용자가 바로 이해하기 쉬움 |
| 색채 심리 코칭 | **HUSIM COLOR 1:1 Colour Psychology Conversation** | Colour Coach / Colour Coaching | 특정 전문가 자격이나 개인 코치 단정 없이 서비스 형태를 설명 |

- 경향 문단에는 `may`, `often`, `might`, `can`을 필요한 자리에 한 번만 둔다.
- `You are…`, `You will…`, `This will…`과 같은 성격·효과의 확정형을 피한다.
- 일상 실천에는 `You could…`, `You might…`, `Try…`를 사용한다.
- `Recovery Direction`은 역할명에, `ease`, `rest`, `readjust`, `regain balance`는 생활 실천 문맥에 사용한다.
- 미국 영어 우선 출시를 결정하면 `colour`를 `color`로 UI·PDF·이메일 전체에서 한 번에 바꾼다. 의미와 역할 체계는 바뀌지 않는다.

## 5. 전체 현지화 전 구현 원칙

- 한국어 canonical analysis key/data를 유지하고 `ko` / `en` / `zh-CN` locale pack을 분리한다.
- 결과 생성 시 locale과 `copyVersion`을 analysis result·order/session·relationship snapshot·PDF payload·outbox metadata에 저장한다.
- 화면·PDF·자동 이메일은 저장된 locale의 동일 payload를 사용한다.
- 기존 한국어 결과·스냅샷·private PDF·주문·outbox는 변환, 재생성, 재발송하지 않는다.
- 정적 현지화 데이터와 버전 관리된 템플릿을 사용한다. 요청마다 AI로 번역하면 결과 일관성, 비용, 지연, 개인정보 범위가 불안정해지므로 사용하지 않는다.

## 6. 파일럿 보호 장치

- 중국어·영어 파일럿은 동일한 **고정 가상 입력**만 사용한다.
- 로그인, 고객 데이터, 결제, 쿠폰, DB, 자동 이메일, 기존 private PDF, immutable snapshot을 읽거나 쓰지 않는다.
- 이 가이드는 전체 번역 확대나 운영 다국어 배포 승인이 아니다.
