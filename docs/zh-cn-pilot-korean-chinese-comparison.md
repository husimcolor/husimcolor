# 개인 심화 중국어 간체 파일럿 — 문안 이력 및 최종 대조표

- **고정 가상 입력:** 레드·블루·화이트 / 레드 삼각형·블루 마름모·화이트 네모
- **한국어 원문 기준:** `/tmp/zh-cn-pilot-source-payload.json`
- **목적:** 전체 현지화 전, 한국어 원문의 정보량·컬러/도형 근거·코칭 말투를 보존하는 중국어 간체 문안을 검토하기 위한 샘플
- **제외 범위:** 고객 데이터, 로그인, 결제, 쿠폰, DB, 자동 이메일, Production

## 확정 용어

| 한국어 기준안 | 중국어 간체 | 역할 |
|---|---|---|
| 주기질 | **主要心理特征** | 1번째 선택 컬러의 기본 성향 |
| 보조기질 | **辅助心理特征** | 2번째 선택 컬러의 보완 성향 |
| 보완컬러 | **调和色** | 3번째 선택 컬러의 균형 역할 |
| 추천 보완 컬러 | **推荐调和色** | 결과 기반으로 별도 제안되는 컬러 |
| 무의식 | **潜意识** | 1번째 심리카드 |
| 현재흐름 | **当前状态** | 2번째 심리카드 |
| 회복방향 | **恢复方向** | 3번째 심리카드 |

> 현재 한국어 운영 소스에는 3번째 컬러를 `회복방향`으로, 3번째 심리카드를 `다음 방향` 또는 `회복 방향`으로 표시하는 혼재가 있습니다. 이 파일럿은 **향후 통일 기준안**만 적용하며, 운영 한국어 원문은 변경하지 않습니다.

## 수정 이력 구분

| 단계 | 검토 초점 | 상태 |
|---|---|---|
| 1차 | 한국어식 문장 구조·직역 표현 완화, 표지/제목/조화색 설명 자연화 | 이력 보존 |
| 2차 | `厘清`·`复核`·`推进` 등의 업무 문서식 표현을 일상어로 보정하고, 경향 표현의 과도한 반복 또는 단정형 조정 | 이력 보존 |
| 3차 | 상대의 말을 듣는 판단, 카드·관계·그림자 문장의 자연화 | 이력 보존 |
| **4차 현재** | 운영 한국어 데이터 정의 감사 후 **3번째 컬러 `调和色`**와 **3번째 카드 `恢复方向`**을 분리, 계산형 추천은 `推荐调和色`로 구분 | **현재 PDF·화면 적용본** |

## 현재 최종 문안 대조

| 항목 | 한국어 원문 | 초기/이전 표현 | **4차 현재 중국어** | 판단 |
|---|---|---|---|---|
| 표지 | 색과 도형을 통해 현재의 내면, 삶의 역할, 회복 리듬을 살핍니다. | 温和地看看 | **通过色彩与图形，了解当下的内心感受、社会角色与自我调节的方向** | 따뜻함을 형용사 반복이 아닌 배려하는 문장 구조로 전달 |
| 카드 섹션 | 카드의 흐름 | 卡片的流动 | **三张卡所呈现的心理变化** | 직역 느낌을 줄이고 카드 기능을 명확히 함 |
| 판단 흐름 | 할 일이 생기면 먼저 방향을 정하고 말을 충분히 듣고 판단하는 편입니다. | 再了解相关信息，作出判断 | **面对需要处理的事情，你往往会先明确方向，充分听取对方的想法后，再作判断。** | ‘상대의 말을 충분히 듣는’ 의미 복원 |
| 성격 흐름 | 일의 우선순위를 빠르게 잡습니다. 듣고 생각한 뒤 답을 냅니다. | 你能较快厘清工作的轻重缓急 | **你往往能较快理清事情的轻重缓急；了解相关信息、想一想后再回应，并在结束前确认是否有遗漏。** | 일상어와 경향 표현을 함께 유지 |
| 관계 성향 | 서로의 생각을 분명히 나누며 방향을 맞추고 싶어 합니다. | 一起把方向协调好 | **你可能更希望把彼此的想法说清楚，一起找到双方都能接受的方向。** | 기계적인 ‘조율’ 대신 관계 맥락을 살림 |
| 카드 1 | 1번 카드 · 무의식 | 潜在心理倾向 | **第1张卡 · 潜意识** | 원개념 보존 |
| 카드 2 | 2번 카드 · 현재 흐름 / 지금의 반응 | 当前状态 | **第2张卡 · 当前状态 / 当下的反应** | 상태와 반응을 구분 |
| 카드 3 | 운영 화면은 다음 방향·회복 방향 혼용, 데이터 역할은 회복 방향 | 下一步方向 | **第3张卡 · 恢复方向** | `cardData.ts`의 `recoveryDirection` 정의에 맞춤 |
| 컬러 3 | 운영 화면은 회복방향, 향후 기준은 보완컬러 | 恢复方向 | **调和色** | 심리카드 회복방향과 명확히 분리 |
| 계산형 추천 | 현재 결과가 제안하는 보완 컬러 | 调和色 | **推荐调和色** | 선택 컬러와의 혼동 방지 |
| 화이트 실천 | 필요할 때 할 일을 정리해 깔끔하게 마무리하는 방식으로 균형을 잡습니다. | 列出待办、逐项完成 | **不妨把要做的事情列下来，一件件完成，重新找回自己的节奏。** | 일상어로 자연화 |
| 그림자 | 충분히 알아본 뒤에야 움직이려다 시작이 늦어지는 편 | 开始的时点容易往后拖 | **想等了解得更充分后再行动，因此容易迟迟没有开始。** | 원문의 ‘시작이 늦어짐’을 명확화 |
| 샘플 표시 | 공개 예시 리포트 · 가상 데이터로 생성됨 · 실제 고객 개인정보 미사용 | 公开审核样本 | **报告示例 · 由虚拟数据生成 · 未使用真实客户个人信息** | 공개 리포트 예시 성격을 자연스럽게 전달 |
| 조화색 설명 | 현재 흐름에서 과해지기 쉬운 결을 누그러뜨리고, 회복 방향을 돕는 컬러입니다. | 교정·치료처럼 들리는 번역 | **这些颜色可作为日常自我调节的参考，帮助你放松身心、找回平衡，而不是要求你改变自己。** | 자기조절 참고라는 코칭 뜻 유지 |

## 문체 기준

- 심리 경향에는 `可能`·`往往`·`更倾向于`를 **한 문단에 필요한 지점 한 번만** 씁니다.
- `你擅长`·`你会`·`都能` 같은 확정적 능력·효과 표현을 피하고, 행동 제안에는 `不妨`·`可以`을 사용합니다.
- `恢复方向`은 카드의 역할명, `调整状态`·`放松`·`休息`·`找回平衡`은 일상 실천의 문맥으로 구분합니다.
- 컬러·도형 원문, 강점, 지칠 때 특징, 세 컬러 통합, 카드 순서, 사회 역할, 오행·일상 실천을 삭제하거나 새 근거 없이 추가하지 않습니다.

## 상세 감사 문서

운영 한국어의 실제 표기 위치, PDF·관계 리포트의 혼용 지점, 영어 파일럿의 대응안은 [역할 용어 감사 및 중국어 v3 기반 번역 가이드](./localization-role-audit-and-guide.md)를 기준으로 확인합니다.

## 범위와 보호 장치

- 화면과 PDF는 같은 고정 가상 데이터를 사용하며, 고객 데이터·기존 결과·PDF·자동 이메일에는 접근하지 않습니다.
- 이 문서는 **4차 역할 정렬 파일럿 문안**의 검토 기준입니다. 전체 중국어 번역 확대와 Production 배포는 별도 승인 이후에만 진행합니다.
