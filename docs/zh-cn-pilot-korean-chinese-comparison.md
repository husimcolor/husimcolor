# 개인 심화 중국어 간체 파일럿 — 한국어·기존·수정 중국어 대조

- **고정 가상 입력:** 레드·블루·화이트 / 레드 삼각형·블루 마름모·화이트 네모
- **목적:** 전체 현지화 전, 문장 자연스러움·용어·브랜드·코칭 톤을 함께 검토하기 위한 중국어 간체 샘플
- **제외:** 고객 데이터, 로그인, 결제, 쿠폰, DB, 자동 이메일, Production
- **변경 원칙:** 한국어 원문의 해석 순서와 컬러·도형 근거를 보존하고, 심리 진단이나 예측처럼 단정하지 않는다. 다만 모든 문장에 `可能`·`也许`·`或许`를 반복하지 않고, 행동 제안에는 `不妨`·`可以`을 사용한다.

## 제목·개념 검토

| 한국어 개념 | 기존 중국어 | 수정 중국어 | 채택 이유 / 대안 |
|---|---|---|---|
| 성장 방향 | 可能留意的成长方向 | **值得关注的成长方向** | 제안대로 채택. ‘可能’보다 자연스럽고, 성장 과제를 단정하지 않는다. |
| 무의식 흐름 | 潜在心理流向 | **潜在心理倾向** | 제안대로 채택. `流向`은 물리적 방향감이 강해 심리적 경향에는 `倾向`이 자연스럽다. **대안:** `潜意识倾向`은 ‘무의식’ 원뜻에는 더 가깝지만 임상적 뉘앙스가 조금 강할 수 있어, 파일럿에는 `潜在心理倾向`을 사용했다. |
| 현재 내면의 흐름 | 此刻内心的流动 | **当下的内心变化** | 제안대로 채택. 결과를 고정된 상태로 말하지 않으면서도 중국어 문장으로 자연스럽다. |
| 나의 삶의 역할 에너지 | 我的生命角色能量 | **我的社会角色与优势** | 제안대로 채택. `生命角色能量`은 직역 느낌이 강하다. 다만 ‘에너지’의 흐름 비유는 줄어든다. **대안:** `我的社会角色与内在动力`는 에너지 비유를 조금 더 남기고 싶을 때 쓸 수 있다. |
| 역할 에너지의 그림자 | 角色能量的阴影面 | **需要留意的一面** | 제안대로 채택. 부정적 낙인 없이 과부하·반복 패턴을 살피게 한다. **대안:** `需要注意的倾向`은 더 분석적인 표현이다. |
| 오늘의 회복 메시지 | 今天的恢复讯息 | **今天给自己的话** | 제안대로 채택. 더 일상적이고 친근하다. |

## 유형명 검토

한국어 원문 **`정보를 판단으로 바꾸는 전략 해석가형`**은 ‘복잡한 정보에서 핵심을 찾고, 선택지를 비교해 다음 행동을 정하는 강점’을 말한다.

| 안 | 중국어 유형명 | 평가 |
|---|---|---|
| 기존 | 把信息转化为判断的策略解读者型 | 의미는 남지만 명사 연결이 길고 ‘解读者’의 대상이 모호하다. |
| **파일럿 채택** | **信息梳理与判断型** | 짧고 이해하기 쉽다. ‘정보를 구조화하고 판단한다’는 원문의 핵심을 유지한다. |
| 대안 | 信息分析与决策型 | 직무·능력 모델 같은 인상이 강해질 수 있다. |
| 대안 | 策略判断与整合型 | 전략적 뉘앙스는 살지만 일상 언어로는 다소 딱딱하다. |

## 서비스명·브랜드 표기 검토

파일럿에는 브랜드를 번역 확정하지 않고 **`HUSIM COLOR`**로 표기했다. 1:1 안내의 서비스 표현은 **`1:1 色彩心理对话`**를 사용한다.

| 항목 | 표현 | 검토 |
|---|---|---|
| 브랜드 유지안 | **HUSIM COLOR** | 현재 브랜드 표기를 보존하며, 중국어 고유명 번역을 임의로 확정하지 않는다. 파일럿 채택안. |
| 중국어 브랜드명안 | 休心色彩 | 따뜻한 인상은 있으나, 상표·도메인·시각 정체성과 함께 별도 승인 후에만 사용할 것을 권장한다. |
| 중립 서비스명 | **色彩心理对话** | 대화·자기이해 중심을 자연스럽게 전달하고, 자격·치료를 암시하지 않아 파일럿에 적합하다. |
| 비교안 | 色彩心理辅导 | 코칭보다 전문적 지원을 뜻하지만, 자격이나 상담 서비스로 오인될 가능성이 있어 실제 제공 범위·현지 규제 검토 뒤 사용해야 한다. |
| 비교안 | 色彩教练 | ‘코치 개인’ 또는 코치 양성 서비스처럼 들릴 수 있어 사용자용 서비스명으로는 우선순위가 낮다. |

## 문체·표현 원칙

1. 심리 경향이 아닌 사실을 단정하지 않는다. 불확실성이 필요한 곳에서만 `可能`·`会`·`容易`를 한 번 사용한다.
2. 실천 제안에는 `不妨…`·`可以…`를 우선 사용해 자연스럽게 권한다.
3. `恢复`는 보고서 전체에서 기계적으로 반복하지 않는다. 맥락에 따라 `调整状态`(상태 조정), `休息`(휴식), `放松`(이완), `找回平衡`(균형 회복)을 사용한다.
4. `调和色`은 정정·치료 수단이 아니라, 현재 리듬에서 과해지기 쉬운 부분을 완화하고 균형을 돕는 색채 참고로 설명한다.
5. 본 문안은 심리 진단·치료·예측이 아닌 자기이해와 일상 웰니스 참고를 위한 코칭 문안이다.

## PDF 전체 범위

수정 PDF는 한국어 개인 심화 공개 샘플의 같은 고정 데이터를 기준으로 다음 내용을 모두 중국어 간체로 제공한다.

1. 표지와 세 컬러
2. 주요 심리 특성·보조 심리 특성·조정 방향의 컬러별 상세 해석, 강점, 지칠 때의 특징
3. 세 컬러 통합 해석, 주요 장점, **值得关注的成长方向**, 관계 성향
4. 세 장의 심리카드와 내면의 바람·현재 상태·조정 방향
5. 调和色, 색채 성향, **当下的内心变化**
6. **我的社会角色与优势**, 사회 역할에서의 활용 방향, **需要留意的一面**
7. 오행 관점의 당면 신체·마음 상태
8. 맞춤 조정 연습, 1:1 색채 심리 대화 안내, 비의료 고지
