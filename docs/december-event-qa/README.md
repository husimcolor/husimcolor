## 서버 구현

## DB 변경과 복구

scripts/december-report-event-migration.mjs는 기본 실행 시 접속하지 않습니다. 읽기 전용 inspect에는 명시한 DB 이름이 필요합니다. apply에는 백업 확인이 필요하고, 원격 적용에는 운영 승인과 hostname|pathname의 비식별 SHA-256 대조가 추가로 필요합니다. DB 동일성은 이 플래그를 넣었다는 이유만으로 확인되는 것이 아니라 기존 운영 연결 기록과 먼저 대조해야 합니다.

문제가 있으면 소스는 이전 운영 배포로 되돌리고 이벤트 쿠폰의 신규 사용만 중지합니다. 이미 발급·사용·예약된 원장과 기존 주문·결제·리포트는 보존합니다. 활성 결제의 처리 상태를 확인하기 전 예약을 TTL만으로 해제하거나 원장을 삭제하지 않습니다. 테이블·쿠폰 삭제는 이 스크립트가 수행하지 않으며, 사용 기록이 전혀 없고 별도 백업·승인이 있는 경우에만 별도 절차를 검토합니다.
