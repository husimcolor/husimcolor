## 1. 이번 보정 범위

이번 v8.1은 전면 재번역이나 전 조합 재검수가 아닙니다. 사용자가 v8 부부·연인 PDF에서 지정한 두 문장과, 동일 한국어 canonical source를 사용하는 **공통 zh-CN 변환 경로**만 수정했습니다.

| 항목 | 한국어 canonical source | 수정된 zh-CN 출력 | 적용 경로 |
|---|---|---|---|
| 블루그린 회복방향 | `생각으로 정리하기 어려운 감정은 말이나 글로 가볍게 꺼내보세요. 논리와 마음을 함께 살피는 시간이 도움이 될 수 있습니다.` | `有些情绪光靠想很难理清，不妨用说出来或写下来的方式慢慢表达。给自己一点时间，兼顾理性的思考和内心的感受，也许会有所帮助。` | `ZH_CN_STATIC_REVISED_COPY` → `localizeStaticCopy` → 개인/관계 PDF 및 동적 결과 payload. 무료 3컬러의 블루그린 문안은 이미 같은 문안이 `ZH_CN_FREE_COLOUR_COPY_PILOT`에 있었음을 재확인. |
| 관계 성향 | `관계 안에서 진심과 활기를 나누고 싶어 하는 성향이 있습니다. … 회복 방향에서는 중요했던 마음을 성찰해 작은 대화나 실천으로 이어갈 때 관계의 의미를 다시 살필 수 있습니다.` | `…当你回顾那些曾经重视的心意，并尝试通过简短的对话或小小行动延续其中的意义时，也可以重新审视这段关系的意义。` | `ZH_CN_REVIEWED_OUTPUT_OVERRIDES` → `localizeStaticCopy` → 관계 결과 화면/PDF payload |

`틸`은 공통 최종 정규화와 locale pack에서 계속 **蓝绿色**로 고정됩니다.

## 2. 확인한 실제 출력

### 수정된 기본 부부·연인 샘플

- 파일: `husimcolor-couple-love-zh-CN-followup-v8.1-20261015.pdf`
- 입력: 한국어 canonical fixture의 남편·아내 가상 데이터
- 출력: 18쪽, `locale: zh-CN`, `copyVersion: zh-CN-2026-10-15-v8.1`
- 시각 확인:
  - **11쪽**: 남편의 `恢复方向 · 蓝绿色`에 지정된 회복 문장이 완결 중국어로 렌더링됨
  - **14쪽**: `当你回顾那些曾经重视的心意` 문장이 관계 성향 문맥에 자연스럽게 렌더링됨
- 구조 스캔: 한국어 잔여, `难以用思维`, `重要过的心意`, `蒂尔色`, `的的`, literal `\\n` 감지 없음

### 재사용한 v8 검토 산출물

이번 v8.1의 두 변경은 개인·부모자녀 fixture 및 추가 대표 연인/아빠·아들/개인 조합의 출력 문장을 바꾸지 않습니다. 불필요한 재생성 대신 아래 v8 산출물을 그대로 보관·제공합니다.

| 산출물 | 버전 | 상태 |
