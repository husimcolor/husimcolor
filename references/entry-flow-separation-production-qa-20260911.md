## 개인 심화분석 직접 진입

운영 첫 화면의 `🎨 컬러 + 심리카드 개인 심화분석 — 29,000원` 카드를 선택했을 때 `/premium-info`로 바로 이동했다. 기존 판매·소개 화면 제목인 `컬러 에너지 흐름 심층 해석`은 나타나지 않았고, 나이·직업·신앙 여부·고민 분야와 `컬러 선택하기 →`가 있는 개인 심화분석 정보 입력 화면이 표시됐다.

## 관계 상품과 정보 입력 분리

운영 첫 화면의 `💞 관계 분석` 카드는 `/couple-start`의 기존 세 상품 선택 화면으로 이동했다. 이 화면에는 다음 세 상품만 표시됐으며, 두 사람의 성별·종교 입력 폼은 표시되지 않았다.

| 상품 | 가격 |
|---|---:|
| 💖 부부 · 연인 관계 심화분석 | 59,000원 |
| 👨‍👩‍👧 부모 · 자녀 관계 심화분석 | 39,000원 |
| 🌿 친구 관계 분석 | 무료 |

`🌿 친구 관계 분석` 선택 뒤 `다음 · 두 사람 정보 입력하기 →`를 누르면 `/couple-info?relationType=친구`로 이동했다. 이 별도 화면에는 첫 번째 사람과 두 번째 사람 각각의 기존 성별·종교 입력 항목 및 `첫 번째 사람 컬러 선택하기 →`만 표시됐다. 이는 상품 선택 → 정보 입력 → 기존 컬러 선택이라는 요청된 순서를 확인한 것이다.

## 비변경 범위

가격, 세 관계 상품 분리, 기존 입력 항목, 컬러·심리카드 검사, 결과, PDF, 카카오 공유 및 관계 분석 내용은 변경하지 않았다. 브라우저 검증에서는 민감한 실제 개인정보를 입력하거나 세션을 완료하지 않았으며, 기존 검사 이후 결과·PDF·공유 동작은 자동 회귀 테스트로 확인했다.
