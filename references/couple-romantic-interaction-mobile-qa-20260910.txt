부부·연인 통합분석 상호작용·역할·생활 패턴 개편 — 로컬 모바일 QA 기록
일시: 2026-09-10

1. 로컬 Expo Web 미리보기의 390px 모바일 폭에서 커플 세션 시작 화면을 열었다.
2. 부부 관계 유형, 첫 번째 사람(남성/무교), 두 번째 사람(여성/무교)을 선택했다.
3. 첫 번째 사람의 컬러는 레드 → 블루 → 라벤더로 선택했다.
4. 시작·관계 유형·개인 정보·컬러 3단계 선택 UI가 모바일 폭에서 정상적으로 전환되고, 세 번째 컬러 선택 뒤 다음 단계 버튼이 활성화됨을 확인했다.
5. 첫 번째 사람 카드: 레드 육각형 → 오렌지 육각형 → 오렌지 마름모를 선택했고, 기존 개인 통합 분석·코칭·루틴 흐름이 유지된 상태로 두 번째 사람 단계로 전환됐다.
6. 두 번째 사람 컬러: 그린 → 인디고 → 핑크, 카드: 옐로우 삼각형 → 네이비 삼각형 → 옐로우 역삼각형을 선택했다.
7. 부부 통합 결과에서 숫자 관계 점수와 점수 바가 표시되지 않았다. 대신 감정 교류·표현 리듬·갈등 회복 3개 관계 특성이 A/B 개인 문장 인용 없이 상호작용·조율 언어로 표시됐다.
8. 「왜 끌리는데 왜 힘든지」 바로 뒤에 「두 사람의 관계 속 역할 분석」이 표시됐으며, 첫 번째 사람은 「관계를 움직이게 하는 역할」, 두 번째 사람은 「관계의 균형을 잡는 역할」로 동적으로 달랐다. 「두 역할이 만났을 때」에는 보완점·과사용 시 유의점·조율 방향이 함께 표시됐다.
9. 생활 속 관계 패턴은 unifiedSections 기반 비교형 UI 하나만 표시됐다. 재정 관리·집안일·계획 방식·목표 방식마다 A/B 방식과 「둘이 만났을 때 · 조율 포인트」가 표시됐고, 갈등 직후 반응은 별도의 「싸움 패턴」 영역에만 표시됐다.
10. 관계 핵심·연결 방식·스킨십·관계 성장 포인트·추천 컬러·기존 부부 회복 루틴은 함께 정상 표시됐다.
11. 동일한 A/B 컬러·심리카드 세션에서 관계 유형만 부모-자녀·친구·동료로 전환해 각각 기존 경량 결과가 표시됨을 확인했다. 부모-자녀는 「성장 지원형 관계」, 친구는 「감정 교류형 우정」, 동료는 「역할 분리형 관계」의 기존 경량 카드 구성을 유지했다.
12. 형제자매는 자동화 브라우저 세션 재연결 중 화면 확인이 중단됐으나, `getLightArchetype('형제자매', ...)`가 null이 아닌 경량 결과를 반환하는 회귀 테스트와 화면의 `lightArchetypeResult` 분기 조건으로 보존을 확인했다.
13. Production `https://husimcolor.vercel.app`의 캐시 우회 주소에서 같은 부부 세션을 재검증했다. 상호작용형 3특성·동적 역할 분석·단일 비교형 생활 패턴·별도 싸움 패턴이 로컬 QA와 동일하게 표시됐고 숫자 점수·점수 바는 없었다.
14. Production에서 같은 세션의 부모-자녀·친구·동료를 각각 전환해 「성장 지원형 관계」·「감정 교류형 우정」·「역할 분리형 관계」의 기존 경량 결과가 유지되고, 부부·연인 전용 역할·상호작용·생활·싸움 패턴 UI가 표시되지 않음을 확인했다.
