# 부모·자녀 갈등과 회복 통합 카드 로컬 QA

- 일시: 2026-09-10
- 경로: 로컬 `/couple-result?qa=parent-child-conflict-local-20260910`
- 조합: 아빠-아들
- 입력: 아빠 `red / lavender / teal` + `navy_square / red_triangle / navy_triangle`, 아들 `blue / green / yellow` + `green_inverted_triangle / green_square / blue_triangle`

## 확인 결과

1. 기존 「대화 흐름」과 「갈등 후 회복 방식」 소형 카드는 부모·자녀 결과에서 표시되지 않았다.
2. 「갈등과 회복」 아래 단일 「갈등이 생기는 이유와 다시 연결되는 순서」 카드가 표시됐다.
3. 카드가 갈등이 시작되는 지점 → 아빠가 전하려는 마음 → 아들이 받아들이는 방식 → 관계가 어긋나는 지점 → 회복에 필요한 순서로 이어졌다.
4. 모든 관계 맥락 라벨이 실제 선택 호칭인 아빠·아들로 표시됐고, DO & DON'T의 구체 대화 문장과 갈등 카드의 관계 해석이 역할상 분리됐다.
5. 개인 컬러·심리카드 분석과 추천 컬러·회복 루틴·마무리 흐름은 유지됐다.
