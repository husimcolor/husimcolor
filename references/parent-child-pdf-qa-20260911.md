# 부모·자녀 PDF 리포트 QA 기록

## 고정 샘플

엄마(그린·세이지그린·라벤더, 레드 동그라미·화이트 네모·블루 마름모)와 딸(옐로우·핑크·코랄, 옐로우 동그라미·퍼플 마름모·그린 육각형)의 실제 부모·자녀 분석 데이터를 사용했다.

## 시각 검수 1차

표지와 종합 관계 분석 첫 페이지를 직접 확인했다. 표지에는 `휴심컬러 부모·자녀 감성 심리코칭 리포트`, 실제 호칭 `엄마–딸`, 실제 관계 유형 `신뢰와 탐색의 조율 관계`, 생성일이 한글로 정상 렌더링됐다. 이어지는 종합 관계 분석은 관계 요약과 관계 유형 카드가 한글 깨짐 없이 표시됐고, 텍스트·카드·섹션 바가 페이지 경계를 넘어 잘리지 않았다.

다음 검수에서는 종합 분석 하단, 첫 번째 사람 새 페이지 시작, 두 번째 사람 새 페이지 시작, 개인 카드의 줄바꿈과 데이터 일치를 추가로 확인한다.

## 시각·텍스트 검수 2차

샘플 PDF는 A4 19페이지로 생성됐다. 종합 관계 분석은 2페이지부터 시작해 11페이지에서 마무리됐고, `첫 번째 사람 - 엄마` 개인분석은 12페이지, `두 번째 사람 - 딸` 개인분석은 16페이지의 새 페이지 상단에서 각각 시작했다. 개인 컬러·심리카드 카드, 통합 분석, 관계 성향과 회복 방향은 한글 폰트로 정상 렌더링됐으며 카드 제목만 남거나 카드 내용이 페이지 중간에서 잘리는 현상은 확인되지 않았다.

웹과 PDF의 데이터 일치도 확인했다. 표지의 엄마–딸 호칭과 `신뢰와 탐색의 조율 관계`, 종합 분석의 추천 컬러·세 가지 실천·마무리 메시지, 두 개인의 컬러 3개와 심리카드 3장은 생성 원본 JSON과 일치했다. 두 사람의 현재 심리카드 흐름도 종합 분석 첫 카드에 웹의 2번 카드 서술을 그대로 전달하도록 보완했다.

## 시각 검수 3차

현재 심리카드 흐름을 추가한 최신 PDF의 표지와 종합 분석 첫 페이지를 다시 확인했다. 표지의 제목·엄마–딸 호칭·관계 유형·생성일은 그대로 정상 렌더링됐고, 첫 종합 카드에는 `두 사람의 현재 심리 흐름` 소제목 아래 엄마와 딸의 실제 2번 카드 서술이 자연스럽게 이어졌다. 카드 높이가 내용에 맞춰 늘어나며 하단이 잘리거나 한글 줄바꿈이 겹치는 현상은 없었다.
