# 부모·자녀 전용 결과 모바일 가독성 QA

첨부된 Android 모바일 캡처를 기준으로 부모·자녀 전용 종합 코칭의 가독성 문제를 점검하고 다음 보정을 적용했다.

- 밝은 역할 카드에서 관계 역할 제목·설명·통합 해석이 희미하게 보이던 문제를 각각 `#342820`, `#5D4C42`, `#3B2B50`의 충분한 명도 대비로 교정했다.
- `각자의 사회적 역할`, `우리 관계의 역할 에너지`, `자녀 기질 맞춤 소통`, `부모의 대화 DO & DON'T`, `갈등과 회복`, `추천 컬러`의 섹션 제목을 19px·굵기 800·27px 행간으로 조정했다.
- 부모·자녀 전용 어두운 카드의 제목은 19px·27px 행간, 본문은 16px·29px 행간, 밝은 역할·대화·추천 컬러 카드는 15.5~16px·26~29px 행간으로 조정했다.
- 카드 내부 패딩과 소제목·본문 간격을 소폭 확대했으며, 하단 회복 루틴과 마무리 카드에도 부모·자녀 전용 텍스트 위계를 적용했다.
- 부부·연인과 친구·동료·형제자매는 공통 기본 스타일 또는 기존 부부·연인 전용 스타일을 그대로 사용하도록 `isParentChildRel` 조건과 `variant="parentChild"`로 범위를 제한했다.
- 전체 회귀는 15개 파일 중 14개 통과·1개 스킵, 95개 통과·1개 스킵으로 완료했고, TypeScript와 diff 공백 검사도 통과했다.

## Production 진입 확인

- `https://husimcolor.vercel.app/couple-start?qa=parent-child-readability-production-20260910`에서 부모·자녀를 선택한 뒤 `아빠 ↔ 아들`, 양측 남성·무교를 설정하고 첫 번째 사람의 컬러 선택 단계까지 정상 진입했다.
- 운영 선택값은 첫 번째 사람 `레드 → 라벤더 → 틸`이며, 다음 심리카드 선택과 종합 결과 화면 확인을 이어서 수행한다.
- 첫 번째 사람의 기존 1단계 컬러 분석 화면에서 컬러·심리 흐름·보완 컬러·관계 성향·감정 표현의 기존 내용과 순서가 유지되는 것을 확인했다. 이번 가독성 보정은 개인 분석을 변경하지 않는다.
- 첫 번째 사람의 심리카드 선택 단계도 운영에서 정상으로 표시되어, 부모·자녀 전용 종합 분석 전 개인 검사 흐름이 유지됨을 확인했다.

## Production 실제 종합 결과 확인

- 첫 번째 사람은 `레드 → 라벤더 → 틸`, `네이비 → 레드 → 네이비` 카드 흐름을, 두 번째 사람은 `블루 → 그린 → 옐로우`, `그린 → 그린 → 블루` 카드 흐름을 선택한 뒤 실제 종합 결과까지 진입했다.
- 결과 요약에는 `아빠-아들 · 감성 심리코칭`과 각 사람의 실제 호칭이 표시됐고, 개인 컬러·심리카드 분석은 기존 흐름을 유지했다.
- 종합 결과에서는 `각자의 사회적 역할`, `우리 관계의 역할 에너지`, `자녀 기질 맞춤 소통`, `부모의 대화 DO & DON'T`, `갈등과 회복`, `추천 컬러`, `함께하면 좋은 회복 루틴`이 부모·자녀 전용 순서로 표시됐다.
- 어두운 배경의 사회적 역할·소통·갈등 카드에서 제목·본문의 대비와 줄간격이 유지됐고, 역할 에너지의 밝은 내부 카드에서도 `아빠 · 관계 속 역할`, `아들 · 관계 속 역할`, `두 역할이 만났을 때` 라벨과 설명이 충분한 대비로 출력됐다.
