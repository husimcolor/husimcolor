# 부모·자녀 관계 유형 및 전체 적용 QA 보고서

> **범위:** 부모·자녀의 통합 관계 분석만을 대상으로 합니다. 개인별 컬러 × 심리카드 분석, 부부·연인, 친구·동료·형제자매 결과에는 적용하지 않습니다.

## 1. 기존 판정 로직 감사 결과

기존 `getParentChildArchetype`에는 사용자가 말씀하신 7개가 아니라 **6개 유형**만 있었습니다. 이 로직은 두 사람의 3컬러를 energy family로 바꾼 뒤, 1순위는 2점·2순위와 3순위는 각 1점으로 합산한 대표 family를 기준으로 판정했습니다. 따라서 3순위 회복 컬러도 관계 유형에 참여했고, 심리카드는 유형에는 참여하지 않지만 별도의 부모·자녀 통합 문장 생성에서는 역할 키를 바꾸는 데 쓰였습니다.

새 전체 적용 모듈은 이 경로를 부모·자녀 통합 분석 화면에서 대체합니다. 새 유형은 **두 사람의 1·2순위만**으로 판정하며, 3순위와 심리카드는 유형·생활 장면의 주근거에 참여하지 않습니다.

## 2. 새 7개 유형과 판정 조건

아래 조건은 비율 조정을 위한 가중치나 무작위 선택이 아닙니다. **1순위는 관계 유형의 주된 방향**, **2순위는 역할·생활 장면·대화에서 그 방향을 구체화하는 보조 차원**으로 분리해 사용합니다. 1순위의 관계 차원 조합은 모두 명시적으로 일곱 유형 중 하나에 연결하며, 임의의 넓은 폴백으로 처리하지 않습니다. 따라서 2순위가 1순위의 관계 방향을 역전시키지 않습니다.

| 유형 | 핵심 판정 조건 | 관계 해석의 중심 | 대표 1·2순위 조합 |
|---|---|---|---|
| 안정과 회복의 동행 관계 | 두 사람의 주된 차원이 모두 안정·돌봄 | 신뢰, 지속성, 무리 없는 돌봄 | 엄마 그린·세이지그린 / 자녀 올리브·베이지 |
| 정서 공감의 연결 관계 | 두 사람의 주된 차원이 모두 돌봄·연결 | 공감, 관심, 마음의 온도 | 엄마 핑크·피치 / 자녀 오렌지·핑크 |
| 기준과 이해의 균형 관계 | 두 사람의 주된 차원이 모두 기준·이해 | 이유, 기준, 판단의 순서 | 엄마 옐로우·틸 / 자녀 화이트·실버 |
| 표현과 활력의 확장 관계 | 두 사람의 주된 차원이 모두 표현·추진 | 시도, 표현, 활력 | 엄마 레드·오렌지 / 자녀 레드·마젠타 |
| 독립과 거리의 존중 관계 | 둘 중 한 사람의 주된 차원이 자기 리듬·여백 | 공간, 호흡, 다시 연결되는 시점 | 엄마 인디고·블랙 / 자녀 블랙·실버 |
| 신뢰와 탐색의 조율 관계 | 한쪽은 안정·돌봄, 다른 쪽은 이해·연결을 주로 둠 | 안전한 기반과 질문의 공존 | 엄마 그린·세이지그린 / 자녀 옐로우·핑크 |
| 서로 다른 속도의 조정 관계 | 표현·추진과 안정·기준의 시작 순서가 다르거나 위 조건에 속하지 않는 실제 차이 | 시작, 확인, 조율의 순서 | 엄마 레드·골드 / 자녀 그린·블루 |

> **우선순위:** 자기 리듬·여백이 주된 경우에는 독립과 거리의 존중 관계를 먼저 읽습니다. 공감·연결이 양쪽의 주기질인 경우에는 정서 공감의 연결 관계를 먼저 읽습니다. 이후 안정·탐색·속도 차이를 실제 주된 차원으로 구분합니다.

## 3. 1·2순위 전수 조합 분포

각 사람의 1순위·2순위가 서로 다른 모든 순서쌍은 25 × 24 = 600개입니다. 부모 600개와 자녀 600개를 조합한 **360,000개**를 전수 검사했습니다. 이 계산에서는 3순위는 고정 회복값, 심리카드는 고정 보조값으로 두었으며, 새 유형 엔진이 이 값들로 달라지지 않음을 별도 테스트로 확인했습니다.

| 유형 | 조합 수 | 비율 |
|---|---:|---:|
| 안정과 회복의 동행 관계 | 34,560 | 9.60% |
| 정서 공감의 연결 관계 | 20,736 | 5.76% |
| 기준과 이해의 균형 관계 | 62,208 | 17.28% |
| 표현과 활력의 확장 관계 | 48,960 | 13.60% |
| 독립과 거리의 존중 관계 | 55,296 | 15.36% |
| 신뢰와 탐색의 조율 관계 | 69,120 | 19.20% |
| 서로 다른 속도의 조정 관계 | 69,120 | 19.20% |

분포는 인위적으로 평준화하지 않았습니다. 특히 ‘서로 다른 속도의 조정 관계’는 표현·추진과 안정·기준이 실제로 엇갈리는 조합만 받습니다. ‘기준과 이해의 균형 관계’와 ‘표현과 활력의 확장 관계’는 공통 차원 또는 명시적 교차 차원에서 각각 도달합니다. 추후 실사용 조합에서 과도한 반복이 보이면 **분포를 맞추는 조정이 아니라 컬러 차원 매핑의 타당성**을 다시 검토해야 합니다. 모든 유형은 대표 조합 테스트에서 실제 도달함을 확인했습니다.

## 5. 새 통합 분석의 섹션 역할 분리

| 섹션 | 분석 역할 | 반복 방지 원칙 |
|---|---|---|
| 관계 요약·역할 에너지 | 1·2순위가 관계에 더하는 중심 차원을 설명 | 관계 유형의 고정 문구를 재사용하지 않음 |
| 자녀 기질 맞춤 소통 | 자녀 1·2순위가 닫히거나 자신감을 얻는 조건 | 현재 카드로 반응의 강도만 보완 |

| 부딪히는 생활 장면 | 실제 차이 축이 선명한 장면 1개 | 생활 영역 목록을 미리 채우지 않음 |

| 3가지 실천 | 약속·공통 강점·회복을 각각 한 번에 실행할 행동으로 분리 | 직접 대화 문구와 갈등 해설을 반복하지 않음 |

## 6. 배포 전 확인 상태

- 새 로직은 부모·자녀 관계 통합 결과에만 연결했습니다.
- QA 고정 엄마·딸 경로는 계속 개발 환경 전용으로 유지됩니다.
- 기존 6유형 경량 데이터는 공유 호환성 및 화면 진입 조건에 남아 있지만, 부모·자녀 결과 화면의 관계 요약·추천 컬러·마무리·통합 코칭 문장은 새 7유형 분석을 우선 표시합니다.
- Production 게시 전 전체 회귀·TypeScript·모바일 화면 및 대표 조합을 추가 확인해야 합니다.
