# 각자 휴대폰 관계 검사 — 사용자 화면 검토

작성일: 2026-09-30
상태: **개발 환경 검토용 · Production 미배포**

> 아래 화면은 개발 DB의 전용 테스트 세션으로 재현했습니다. 실제 사용자 결제·실제 Resend 이메일은 발송하지 않았습니다. 완료 화면은 private PDF 생성 뒤 개발용 outbox만 `sent`로 전환해 확인했습니다.

## 확인 순서

| 순서 | 화면/상태 | 사용자가 확인하는 핵심 문구·버튼 |
|---:|---|---|
| 1 | 검사 방식 선택 | `한 휴대폰에서 함께 검사하기`, `각자 휴대폰에서 검사하기` |
| 2 | 결제자 사전 정보 | 성별·관계 역할·종교·동의, `내 검사 시작하기 →` |
| 3 | 결제자 검사 | 기본 정보 저장, 컬러 3가지, 심리카드 3장, `검사 최종 제출` |
| 4 | 상대방 초대 링크 접속 | `관계 검사에 참여해 주세요`, 상대 역할 안내 |
| 5 | 상대방 검사 | 역할 제한·컬러·심리카드·최종 제출 |
| 6 | 결제자 대기 | `상대방에게 검사 링크 보내기`, `상태 새로고침` |
| 7 | 두 사람 제출 후 | `관계 리포트를 생성하고 있습니다.` |
| 8 | 완료 결과/PDF | 실제 역할 기반 결과, `PDF 리포트 다운로드` |
| 9 | 완료된 초대 링크 재접속 | `이미 완료된 검사입니다. 검사 결과가 정상적으로 생성되었습니다.` |

## 1. 검사 방식 선택

![검사 방식 선택](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/01-mode-selection.webp)

- 제목: **검사 방식을 선택해 주세요**
- 기존 경로 카드: **한 휴대폰에서 함께 검사하기** / `기존 방식으로 시작하기 →`
- 신규 경로 카드: **각자 휴대폰에서 검사하기** / `초대 링크 방식으로 시작하기 →`
- 안내: 상대방이 브라우저를 닫아도 완료 전까지 동일 링크로 이어서 검사할 수 있음을 알립니다.

## 2. 결제자 본인 정보 및 관계 역할

![결제자 사전 정보](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/02-owner-preparation.webp)

- 제목: **먼저 본인 검사를 시작해 주세요**
- 선택: `남성` / `여성`, 관계 역할, `기독교` / `무교` / `기타`
- 동의 문구: `관계 검사 결과 생성을 위해 선택한 정보와 검사 답변을 안전하게 처리하는 데 동의합니다. 상대방의 답변은 별도 링크에서 본인이 직접 입력합니다.`
- 필수 선택 전에는 **내 검사 시작하기 →** 버튼이 비활성 상태입니다.

## 3. 결제자 검사 — 기본 정보, 컬러, 심리카드

![결제자 검사](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/03-owner-inspection.webp)

- 상단: **내 마음 흐름을 선택해 주세요**
- 기본 정보: 성별이 `남성`이면 관계 역할은 `남편`만 표시되는 예시입니다.
- 검사 단계:
  1. **기본 정보 및 참여 동의** / `기본 정보 저장`
  2. **마음이 이끄는 컬러 3가지** / `3 / 3 컬러 단계 저장`
  3. **심리카드 3장** / `검사 최종 제출`
- 컬러와 심리카드는 3개가 모두 선택되면 자동 저장되며, 동일 링크 재접속 시 복원됩니다.

## 4. 상대방 초대 링크 접속 및 역할 제한

![상대방 링크 접속](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/04-partner-link-entry.webp)

- 상단: **초대받은 검사** / **관계 검사에 참여해 주세요**
- 안내: `선택 내용은 이 초대 링크의 관계 세션에만 안전하게 연결됩니다.`
- 결제자가 `남편`으로 저장된 예시에서 상대방에게는 다음 문구가 보입니다.
  - `상대방은 남편 역할을 선택했습니다. 가능한 역할만 표시합니다.`
  - 여성 선택 시 관계 역할은 **아내**만 표시됩니다.
- 상대방도 종교, 동의, 컬러 3개, 심리카드 3개를 자신의 기기에서 직접 선택하고 `검사 최종 제출`합니다.

## 5. 결제자 대기 및 초대 공유

![상대방 검사 대기](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/05-owner-waiting.webp)

- 제목: **내 검사 제출 완료**
- 안내: `상대방 검사 대기 중입니다. 두 사람이 모두 최종 제출한 뒤에만 관계 리포트를 생성합니다.`
- 버튼:
  - **상대방에게 검사 링크 보내기** — Web Share 또는 링크 복사를 실행합니다.
  - **상태 새로고침** — 상대방의 제출 상태를 다시 확인합니다.

## 6. 두 사람 제출 후 리포트 생성 상태

![리포트 생성 중](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/06-report-generating.webp)

- 제목: **검사 제출 완료**
- 안내: `두 사람의 답변을 확인했습니다. 관계 리포트를 생성하고 있습니다.`
- 이 상태에서는 입력·재제출이 잠깁니다. 서버가 한 번만 PDF/outbox 생성을 선점합니다.

## 7. 완료 결과 및 PDF 다운로드

![완료 결과와 PDF](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/07-result-pdf.webp)

![PDF 다운로드 버튼](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/08-result-pdf-download.webp)

- 결과 상단은 **남편 / 아내**처럼 실제 관계 역할로 표시됩니다.
- 관계 분석의 역할 카드와 생활 패턴도 실제 역할 이름을 사용합니다.
- 하단 버튼: **PDF 리포트 다운로드**
- PDF와 이메일 outbox가 정상 처리된 후에만 관계 세션이 completed로 전환됩니다.

## 8. 완료된 초대 링크 재접속

![완료된 링크 안내](/home/ubuntu/hyusim-color/references/relationship-invite-preview-images/09-completed-invite.webp)

- 제목: **검사 완료**
- 안내: `이미 완료된 검사입니다. 검사 결과가 정상적으로 생성되었습니다.`
- 완료된 초대 링크에서는 검사 화면·답변 수정·재제출 버튼을 표시하지 않습니다.
- 결과 조회는 초대 링크와 분리된 결과 토큰 경로에서만 허용합니다.

## 검토 시 확인할 사항

1. 버튼명과 안내 문구가 사용자에게 충분히 명확한지
2. `상대방에게 검사 링크 보내기` 버튼의 위치와 기다리는 동안의 안내가 적절한지
3. 완료 후 초대 링크에서 결과를 보이지 않는 현재 권한 분리가 운영 의도와 맞는지
4. 부부·연인 외에 부모·자녀에서도 동일한 화면 구조와 실제 역할 표기 방식이 자연스러운지
