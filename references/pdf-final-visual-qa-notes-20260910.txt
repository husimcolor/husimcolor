유료 PDF 최종 시각 검수 메모 — 2026-09-10

사용자 제공 모바일 스크린샷 기준 문제:
1. 첫 페이지에 실제 컬러칩이 없고 컬러명/키워드만 텍스트 카드로 표시됨.
2. 3장 심리카드 해석에서 화이트·네이비·블루 카드가 텍스트만 보이고 실제 카드 색상과 도형 미리보기가 없음.
3. `화이트 □ 역삼각형`, `□ 오늘의 말씀` 등 `□` 계열 깨짐 문자가 다수 보임.
4. 회복 루틴 문구 `낙실 시간 에 10분 햇빛 속에 앉아있기` 계열 오타/띄어쓰기 오류가 남아 있음.

수정 후 로컬 생성 PDF 확인 결과:
1. 첫 페이지에 라벤더·피치·크림의 실제 원형 컬러칩과 컬러명·키워드가 함께 표시됨.
2. 3장의 심리카드 해석 상단에 카드 배경색과 도형(역삼각형, 동그라미)을 직접 그린 3개 카드 미리보기가 추가됨.
3. 카드 제목은 `화이트 역삼각형`, `네이비 역삼각형`, `블루 동그라미`처럼 안정적인 문자 조합으로 표시됨.
4. `오늘의 말씀` 제목은 깨진 특수문자 없이 정상 표시됨.
5. 회복 루틴 문구는 `낮 시간에 10분간 햇빛을 쬐며 앉아 있기`로 교정됨.
6. 1~5페이지 시각상 한글 겹침과 카드 중간 잘림은 보이지 않았으며 총 페이지 수는 6페이지로 유지됨.
7. 6페이지에서 `낮 시간에 10분간 햇빛을 쬐며 앉아 있기` 문구, 맞춤 회복 루틴 카드, 1:1 컬러코칭 안내, 하단 웰니스 고지가 페이지 안에 정상 표시되었고 텍스트 잘림·깨진 기호는 보이지 않음.
8. Production attachment로 내려받은 PDF도 1페이지 컬러칩, 2페이지 카드 미리보기, 3페이지 말씀 제목, 5페이지 회복 루틴까지 동일하게 반영되었다.
9. 4페이지의 `이 역할이 더하는 가치` 라벨은 추출 텍스트에서 온전하게 확인됐다. 시각상 시작 글자가 흐릿해 보이지 않도록 삶의 역할 소제목은 모두 명시적 x 좌표와 10.4pt 크기로 보정했다.
