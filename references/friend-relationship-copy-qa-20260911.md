# 친구 관계 문구·공유 QA

## 배포 전 확인

- Production 공유 스냅샷 `c5d1a8ea-4cb8-4d49-a424-48c1572dd36e`는 `친구` 관계와 A의 블루·옐로우·그린, B의 핑크·피치·라벤더 및 선택 심리카드를 독립적으로 복원했다.
- Production은 아직 배포 전 코드이므로 하단 버튼이 기존 `새로운 커플 세션 시작`으로 보였다. 이는 저장된 친구 스냅샷 오류가 아니라 아직 운영 번들이 갱신되지 않았기 때문이다.
- 수정된 로컬 번들은 개발 API가 Production 공유 DB를 조회하지 못해 로딩 상태를 유지했으므로, 문구 확인은 소스 회귀 테스트와 Production 자동 배포 후 운영 링크에서 다시 수행한다.

## 수정 대상

- 친구 관계 카카오 공유 제목: `휴심컬러 친구 관계 분석 결과`
- 친구 관계 카카오 공유 문구: `우리 우정의 관계 유형은 …입니다 🤝`
- 친구 관계 하단 시작 버튼: `새로운 친구 관계 분석 시작`
- 다른 관계 유형의 기존 제목·문구와 결과 구조는 유지

## Production 자동 배포 후 확인

GitHub Actions 실행 `34598728201`이 성공한 뒤, 동일한 친구 관계 shareId를 운영 주소에서 다시 열었다. A의 블루·옐로우·그린, B의 핑크·피치·라벤더 및 각 심리카드가 친구 관계 결과로 독립 복원됐고, 하단 시작 버튼은 `새로운 친구 관계 분석 시작`으로 표시됐다. 이미지 저장과 카카오 공유 버튼도 기존 위치에 유지됐다.

캐시 우회용 추가 쿼리 파라미터가 붙은 URL은 Expo Router의 정적 경로 처리에서 홈으로 이동할 수 있으므로, 공유 URL은 기존 규칙대로 `shareId`만 포함하는 `/couple-result?shareId=…` 형식을 유지한다. 이 원문 공유 URL에서 친구 관계 결과가 정상적으로 복원되는 것을 확인했다.
