# 부부·연인 PDF 행동 지침·띄어쓰기 운영 QA

Production `https://husimcolor.vercel.app/couple-result?qa=couple-pdf-actions-production-20260910`에서 부부 세션으로 PDF 다운로드를 다시 실행했다.

- 버튼 1회 클릭 후 `PDF 다운로드를 시작했습니다.` 안내가 표시됐고, 다운로드 폴더에 `휴심컬러_부부_관계리포트_20260910 (1).pdf`가 실제 저장됐다.
- `file --mime-type` 결과는 `application/pdf`, `pdfinfo` 기준 페이지 수는 15페이지였다.
- `pdftotext` 검수에서 3번 카드 `다음 방향` 영역의 행동 문장이 `•` 글머리표로 분리되어 출력됐고, 일반 1·2번 카드 해석은 줄글로 유지됐다.
- 텍스트 검수에서 `붙어있는 시간보다`는 남아 있지 않았고, PDF 출력 기준으로 `붙어 있는 시간보다`로 교정되도록 확인했다.
- 텍스트 검수에서 `짧은 포옹이나 손 잡기가`는 남아 있지 않았고, PDF 출력 기준으로 `짧은 포옹이나 손잡기가`로 교정되도록 확인했다.
- 시각 검수한 2~5페이지에서 3번 카드의 액션 문장이 줄글처럼 붙지 않고 항목별 줄바꿈과 소폭 여백으로 자연스럽게 분리됐다.
