# 부부·연인 관계분석 문구 검수 및 개정 기록

- 검수일: 2026-10-06
- 적용 범위: **새로 생성되는** 부부·연인 관계분석의 컬러 해석, 심리카드 해석, A/B 통합해석, 결과 화면, PDF 리포트
- 보존 범위: 기존 검사 순서·선택 방식·결제·초대 링크·기존 완료 세션·기존 PDF·기존 이메일 발송 기록

## 검수에서 확인한 주요 문제

| 구분 | 기존 문제 | 개정 기준 |
|---|---|---|
| 컬러·카드 개인 해석 | 선택을 고정 성격, 숨은 감정, 상대의 의도처럼 읽을 수 있는 문장이 섞여 있었음 | 선택 시점의 마음과 관계에서 바라는 방식을 비추는 **가능성의 언어**로 전환 |
| 카드 3장 흐름 | 각 카드에서 비슷한 회복·안정 메시지가 길게 반복되고, 단정적인 내면 서사가 이어질 수 있었음 | 무의식=바람, 현재=대화의 단서, 회복=작은 실천으로 역할을 분리 |
| A/B 통합해석 | 개인 문장을 다시 나열하거나 유형별 생활 문구가 관계 상황과 맞지 않을 수 있었음 | 공통점·차이·갈등 후 순서·구체적 실천을 5개 블록으로 분리 |
| 관계 유형 | 부부와 연인에게 같은 생활 전제의 조언이 섞일 수 있었음 | 부부는 생활·역할·갈등 후 재대화, 연인은 연락·각자의 시간·다음 약속을 기준으로 분기 |
| 회복·신앙 안내 | 추상어와 반복 루틴이 누적될 수 있었음 | 오늘 할 수 있는 행동 한 가지를 우선 제안하고, 기독교/기타 선택에는 강요 없이 선택형 묵상 안내를 제공 |

## 대표 수정 전후 원칙

| 항목 | 수정 전 경향 | 수정 후 예시 |
|---|---|---|
| 컬러 해석 | “무의식 안에는 인정받고 싶은 마음과 상처받고 싶지 않은 긴장이 자리하고 있을 수 있습니다.” | “레드는 분명한 마음을 행동으로 옮길 자리를 떠올리게 합니다. 지금 관계에서 직접적인 반응과 솔직한 확인을 소중히 보고 있을 가능성을 보여줍니다.” |
| 현재 카드 | 심리 상태를 하나의 패턴으로 길게 설명 | “현재 카드는 대화와 분위기의 변화를 살피는 방식을 보여줍니다. 상대의 의도를 짐작하기보다, 지금 필요한 말을 한 문장으로 나누어 보세요.” |
| 회복 카드 | “조용한 산책” 등 같은 회복 활동을 반복 | 선택한 컬러·도형에 따라 `다시 대화할 시간 정하기`, `바쁜 날의 연락 기준 맞추기`, `생활 일을 하나만 조율하기`처럼 서로 다른 행동 제안 |
| 부부 통합 | 일반적 연결·회복 표현 | “생활비·집안일·일정 같은 반복되는 일을 어떻게 나눌지”와 “갈등 뒤 다시 이야기할 시간”을 분리해 다룸 |
| 연인 통합 | 동거·생활 전제의 조언 | “연락 빈도와 다음 만남”, “각자의 시간을 존중하며 안부를 잇는 방법”을 중심으로 다룸 |

## 구현 내용

1. `lib/relationship-copy-revision.ts`
   - 선택한 컬러·심리카드 기반 개인 해석을 생성합니다.
   - 카드 위치별 역할을 분리합니다.
   - 부부/연인별로 다른 5개 통합 블록을 생성합니다.

2. 결과 생성·화면·PDF 연결
   - 새 초대 세션의 서버 스냅샷은 개정된 통합해석을 저장합니다.
   - 결과 화면은 개정 통합해석을 우선 표시합니다.
   - 새 부부·연인 PDF는 동일한 개인 컬러·카드·통합해석 문구를 사용합니다.

3. 중복 방지와 기존 결과 보존
   - 기존 완료 세션의 저장된 스냅샷과 PDF는 재생성하지 않습니다.
   - 기존 이메일 outbox를 다시 실행하지 않습니다.
   - 결과 생성·PDF 저장·이메일 발송 로직은 문구 개정 때문에 새로 호출되지 않습니다.

## 검증

- TypeScript: `pnpm exec tsc --noEmit` 통과
- Vitest: 관계 문구 개정, 컬러·카드 분석, 초대 흐름, 부부·연인 PDF 회귀 테스트 **36건 통과**
- 회귀 테스트는 다음을 확인합니다.
  - 선택 컬러와 문구가 연결되는지
  - 카드 위치별 문구가 서로 다른 역할을 가지는지
  - 부부와 연인별 생활 장면·실천이 달라지는지
  - 결과 화면과 서버 PDF 생성 경로가 같은 개정 모듈을 사용하는지
