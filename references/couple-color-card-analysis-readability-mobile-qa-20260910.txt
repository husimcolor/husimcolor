커플 개인 「컬러 × 심리카드 통합 분석」 모바일 가독성 QA 기록
일시: 2026-09-10

검수 조건
- 모바일 폭 390px, 첫 번째 사람(A)과 두 번째 사람(B) 각각의 실제 렌더링 화면
- A: 핑크·라벤더·그린 / B: 블루·화이트·실버
- 동일한 3장 심리카드 흐름을 사용하여 분석 카드의 A·B 공통 적용과 색상 톤 분리를 확인

확인 결과
1. 두 화면 모두 「핵심 심리와 욕구」, 「겉모습과 내면의 흐름」, 「관계·회복·성장 방향」의 세 소제목과 세 문단이 순서대로 표시됐다.
2. 통합 분석 본문은 16px·27px 줄간격으로 표시됐고, 문단 사이 구분선·상하 여백이 있어 한 문단이 길게 이어지는 인상이 완화됐다.
3. 카드 좌우 여백과 기존 카드별 해석·오늘의 코칭 메시지·회복 루틴의 순서는 유지됐으며, A에는 두 번째 사람 시작하기, B에는 커플 통합 결과 보기 버튼이 계속 표시됐다.
4. 기존 「카드 흐름 통합 분석」 제목은 노출되지 않았고, 새 통합 분석은 컬러 흐름과 무의식·현재·다음 방향의 의미를 세 문단에 나누어 표시했다.

Production 재검수
1. https://husimcolor.vercel.app/couple-card-result 경로에서 캐시 우회 쿼리와 모바일 폭 390px 조건으로 A·B를 각각 확인했다.
2. 두 화면 모두 새 제목과 세 소제목이 표시됐고, 기존 제목은 노출되지 않았다.
3. A에는 두 번째 사람 시작하기, B에는 커플 통합 결과 보기 버튼이 유지돼 기존 A→B→커플 통합 결과 흐름이 보존됐다.
4. 실제 운영 화면에서 16px 본문·27px 줄간격·문단 사이 구분선과 여백이 적용됐으며, 통합 분석 카드의 좌우 여백과 기존 카드별 해석은 변경되지 않았다.
