# 부모·자녀 개인화 보정 QA 기록

## 적용 범위

이번 보정은 부모·자녀 통합 분석의 **자녀 기질 맞춤 소통**과 **갈등과 회복의 관계가 어긋나는 지점**에만 적용했다. 기존 개인별 컬러 × 심리카드 분석, 사회적 역할, 관계 속 역할, DO & DON'T, 갈등 시작, 회복 순서, 우리 관계를 위한 3가지 실천, PDF 및 부부·연인·기타 관계 결과는 변경하지 않았다.

자녀가 마음을 닫기 쉬운 순간은 정서적 트리거로, 자신감을 얻는 순간은 강점이 살아나는 조건으로 분리했다. 1·2순위 컬러를 주근거로 쓰고, 3순위 컬러와 3번 카드는 회복 방향에만 사용했다. 1번·2번 카드는 각각 무의식과 현재 반응을 보완해 실제 오해가 더 커질 수 있는 맥락을 설명하지만, 관계 유형과 생활 장면의 주근거는 바꾸지 않는다.

|---|---|---|---|---|

| 컬러가 다른 아빠–딸: 레드·골드 / 그린·블루 | 서로 다른 속도의 조정 관계 | 약속·기준이 흔들리거나 준비 전에 속도가 앞설 때 | 역할과 순서가 분명한 상황에서 정리한 기준을 적용해 볼 때 | 아빠의 직접 시도·속도와 딸의 안정·정리 리듬이 만나, 속도 제안이 준비 시간을 빼앗는 요구로 읽힐 수 있음 |
| 컬러가 유사하나 카드 흐름이 다른 엄마–아들: 핑크·피치 / 오렌지·핑크 | 정서 공감의 연결 관계 | 마음을 나눌 자리가 빠진 채 결과만 확인될 때 | 관심을 나누고 관계의 반응을 느끼며 연결을 직접 만들어 볼 때 | 엄마의 빠른 공감 확인과 아들의 감정 선택이 만나, 연결 요청이 감정 주도권을 빼앗는 느낌으로 엇갈릴 수 있음 |
| 컬러가 다르나 카드 흐름이 유사한 엄마–딸: 그린·세이지그린 / 옐로우·핑크 | 신뢰와 탐색의 조율 관계 | 이유를 살피기 전에 결론·정답·평가가 요구될 때 | 여러 가능성을 살핀 과정과 세운 이유를 설명할 기회를 얻을 때 | 엄마의 약속·신뢰 기준과 딸의 이유·가능성 탐색이 만나, 기준을 세우는 말이 질문과 선택을 닫는 말로 들릴 수 있음 |

각 조합의 전체 실제 생성 문장은 `parent-child-personalization-examples-20260911.json`에 보관했다.
