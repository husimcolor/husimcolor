# 엄마·딸 우선순위 기반 시범 결과 UI QA

## 목적

사용자가 동일한 심리카드 조합을 다시 선택하지 않아도 검토할 수 있도록, 기존 QA 사례를 실제 부모·자녀 결과 UI에 **로컬 전용**으로 렌더링한다. Production 배포와 전체 로직 적용은 하지 않는다.

## 고정 입력

- 관계: 엄마-딸
- 엄마 컬러: 그린(1순위) · 세이지그린(2순위) · 라벤더(3순위, 회복 방향)
- 엄마 심리카드: 레드 원형 · 화이트 사각형 · 블루 마름모
- 딸 컬러: 옐로우(1순위) · 핑크(2순위) · 코랄(3순위, 회복 방향)
- 딸 심리카드: 옐로우 원형 · 퍼플 마름모 · 그린 육각형

## 시범 적용 원칙

엄마의 그린·세이지그린과 딸의 옐로우·핑크를 생활기질과 관계 장면의 중심 근거로 사용한다. 라벤더·코랄은 회복과 조율 방향에만 사용하고, 심리카드는 현재의 심리 반응과 관계 속도 차이를 보완하는 근거로만 사용한다. 성별·부모자녀 관계만으로 성향을 추가 추정하지 않는다.

## 현재 UI 연결 지점

`couple-result.tsx`는 부모·자녀일 때 `buildParentChildCoaching`의 사회적 역할, 관계 역할 에너지, 자녀 소통, DO & DON'T, 갈등과 회복, 추천 컬러를 순서대로 렌더링한다. 시범 화면은 이 기존 UI를 유지한 채, 로컬 QA 경로에서만 우선순위 기반 시범 데이터로 해당 섹션과 추가 생활 장면을 대체·보완한다. 기존 세 가지 실천과 마무리 카드의 디자인은 재사용한다.

## 실제 로컬 렌더링 QA — 2026-09-11

- 로컬 경로: `/couple-result?qa=mother-daughter-priority-pilot-20260911`
- 접근 조건: `process.env.NODE_ENV !== 'production'` 및 위 QA 쿼리가 동시에 일치할 때만 고정 세션을 메모리에서 로드한다. AsyncStorage 쓰기, 공유 스냅샷 생성·조회, 방문 기록 전송은 실행하지 않는다.
- 확인 결과: 상단에 엄마의 그린·세이지그린·라벤더와 레드 원형·화이트 사각형·블루 마름모, 딸의 옐로우·핑크·코랄과 옐로우 원형·퍼플 마름모·그린 육각형이 정확히 표시되었다.
- 흐름 확인: 로컬 전용 안내 → 근거 → QA 섹션별 근거표 → 각자의 사회적 역할 → 우리 관계의 역할 에너지 → 자녀 기질 맞춤 소통 → 실제 생활에서 만나는 지점(잘 맞는 부분 1개·부딪히는 부분 1개·각 근거) → DO & DON'T → 갈등과 회복 → 추천 컬러 → 우리 관계를 위한 3가지 실천 → 마무리 코칭 메시지 순으로 렌더링되었다.
- 모바일 폭 390px에서 상단 요약, 새 관계 요약, 로컬 전용 안내, 근거 카드와 첫 사회적 역할 카드의 줄바꿈·명도 대비·여백을 확인했다. 전체 텍스트 추출로 QA 근거표, 제한된 두 생활 장면, 이후 필수 섹션과 고정 문구가 존재하는 것도 확인했다.
- 격리 확인: Production 배포·서버 데이터 변경·기존 동적 부모·자녀 코칭 생성기·부부·연인 공유 및 PDF 흐름을 수정하지 않았다.
- Production 읽기 전용 확인: `https://husimcolor.vercel.app/couple-result?qa=mother-daughter-priority-pilot-20260911`에서 브라우저에 존재하던 일반 아빠-아들 세션이 그대로 표시되었고, 고정 엄마·딸 입력·로컬 전용 안내·생활 장면 시범 카드는 나타나지 않았다. 즉 동일 QA 쿼리는 운영 결과 로더를 대체하지 않는다.

## 제한적 생활 장면 재검수 — 2026-09-11

- 사용자 기준에 맞춰 광범위한 생활영역 분류 또는 전 조합 공통 장면 목록을 만들지 않았다.
- 고정 QA에는 1·2순위 컬러의 교차 근거가 명확한 생활 장면만 총 2개를 표시한다. 잘 맞는 장면은 그린·세이지그린의 신뢰·조율과 옐로우·핑크의 이해·공감이 교차하는 ‘하루의 경험을 이유와 감정으로 나누는 저녁’이며, 부딪히는 장면은 안정·정리와 이유 확인·정서 수용의 속도 차이가 교차하는 ‘약속을 확정하는 순간의 속도 차이’이다.
- 라벤더·코랄은 이 두 장면의 현재 기질을 정하는 근거로 사용하지 않고, 갈등 뒤 공감·재연결의 회복 단계에만 남겼다. 화이트 사각형과 퍼플 마름모는 현재 정리·다각도 탐색 반응의 보조 근거다.
- QA 전용 관계 요약, 추천 컬러, 마무리 메시지도 기존 `성장지원형` 경량 템플릿 대신 이 고정 사례의 1·2순위 교차 분석을 바탕으로 표시한다. 이 대체는 개발 환경과 정확한 QA 쿼리가 모두 일치할 때만 적용되며, Production에는 배포하지 않았다.

## 전체 부모·자녀 분석 적용 전 검증 — 2026-09-11

- 전체 부모·자녀 통합 분석은 새 `parent-child-relationship-analysis.ts`로 전환했다. 개인별 컬러 × 심리카드 분석은 변경하지 않았고, 새 분석은 부모·자녀 통합 영역에서만 사용한다.
- 관계 유형은 두 사람의 1순위 컬러가 드러내는 관계 차원을 명시적으로 교차해 7유형으로 판정한다. 2순위는 역할·생활 장면·대화의 구체화에만 쓰며, 3순위는 회복 방향, 심리카드는 무의식·현재·미래 반응의 보조 근거로만 사용한다.
- 생활 장면은 공통 1·2순위 근거가 있을 때만 잘 맞는 장면 1개를 생성하고, 공통 근거가 약하면 해당 장면을 생략한다. 부딪히는 장면은 실제 차이 축이 있을 때만 1개를 생성한다.
- 1·2순위 순서쌍 전체 360,000건을 비무작위 전수 검사했다. 7유형 모두 실제로 도달했으며, 안정·회복 9.60%, 정서 연결 5.76%, 기준·이해 17.28%, 활력 확장 13.60%, 거리 존중 15.36%, 신뢰·탐색 19.20%, 속도 조정 19.20%로 집계되었다. 분포를 맞추기 위한 가중치·랜덤 판정은 사용하지 않았다.
- 전용 테스트는 7유형 대표 조합, 3순위·심리카드 격리, 공통 근거가 없을 때 잘 맞는 장면 생략, 섹션 중복 금지, 호칭·조사 출력을 검증한다. 전체 회귀는 101건 통과, 1건 스킵 상태로 확인했다.

## DON'T·갈등 시작·3가지 실천 개인화 검증 — 2026-09-11

- 수정 범위는 부모·자녀 통합 분석의 DON'T, 갈등과 회복의 ‘갈등이 시작되는 지점’, 우리 관계를 위한 3가지 실천으로 한정했다. 사회적 역할, 관계 속 역할, 자녀 기질 맞춤 소통, UI 구조와 PDF는 변경하지 않았다.
- DON'T는 자녀 1·2순위가 우선하는 필요, 부모 1·2순위가 먼저 지키려는 필요, 7유형의 핵심 긴장, 두 사람의 2번 심리카드가 보완하는 현재 반응을 함께 사용한다. 심리카드는 관계 유형을 바꾸지 않고, 어떤 말이 지금 더 부담스럽게 들릴 수 있는지의 보조 근거로만 쓴다.
- 갈등 시작 지점은 7유형별로 1·2순위 컬러 교차가 실제 충돌이 되는 순간을 설명한다. 예를 들어 신뢰·탐색 조율은 약속·기준과 이유·가능성의 교차, 거리 존중은 연결을 이어가려는 속도와 혼자 정리할 여백의 교차, 활력 확장은 새 시도·표현의 속도와 결과 기대의 교차를 중심으로 분기한다.
- 세 가지 실천은 첫째 유형·1·2순위 긴장에 맞춘 한 번의 행동, 둘째 두 사람의 2번 심리카드가 가리키는 현재 반응을 나누는 행동, 셋째 각자의 3순위 회복 컬러와 3번 심리카드를 회복 단계로만 쓰는 행동으로 역할을 나눴다. 광범위한 생활영역은 추가하지 않았다.
- 회귀 검증에서 신뢰·탐색 조율, 거리 존중, 활력 확장 대표 조합의 DON'T·갈등 시작·3가지 실천은 모두 서로 다른 문장으로 생성됐고, 동일 입력은 같은 결과를 재현했다. 심리카드만 바꾼 경우 관계 유형·생활 장면은 유지하면서 대상 세 섹션의 현재 반응 보완 문장만 달라짐을 확인했다. 전체 회귀는 103건 통과, 1건 스킵 및 TypeScript·공백 검사를 통과했다.
