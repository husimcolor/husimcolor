## 관계 분석 진입

- 첫 화면의 관계 분석 카드를 눌렀을 때 기존 `/couple-start` 화면으로 이동했다.
- 관계 분석 상품 선택에는 정확히 아래 세 항목만 표시됐다.
  - `💖 부부 · 연인 관계 심화분석` / `59,000원`
  - `👨‍👩‍👧 부모 · 자녀 관계 심화분석` / `39,000원`
  - `🌿 친구 관계 분석` / `무료`
- 직장동료와 형제자매는 상품 선택 UI에 보이지 않았으며, 기존 데이터·결과·공유 호환 경로는 이번 첫 화면 변경에서 수정하지 않았다.
