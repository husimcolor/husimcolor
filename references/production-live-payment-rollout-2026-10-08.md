# Production 라이브 결제 전환 기록 — 2026-10-08

## 범위

- 대상: 유료 심화분석 3종의 Toss Payments 라이브 결제 전환 준비
- 상점 MID: 운영 설정 화면에서 확인한 승인 상점
- 결제수단: 승인 완료된 결제수단만 Toss Payments 운영 정책에 따라 제공

## 운영 안전 원칙

- 라이브 클라이언트 키와 시크릿 키는 Vercel **Production Secret** 환경변수로만 저장한다.
- 키 값, 데이터베이스 연결 정보, 고객 개인정보는 문서·코드·로그에 기록하지 않는다.
- 공개 테스트 결제 이용권 부여 경로는 라이브 결제 게이트가 활성화될 때 자동으로 분리·비활성화한다.
- 운영 결제 성공은 기존 주문·결제·이용권 원장을 사용하며, 반복 콜백은 기존 idempotency 보호를 따른다.
- 실제 결제·취소는 사업자가 승인한 운영 절차에서만 검증한다.

## 배포 확인 항목

1. Production runtime이 라이브 결제 준비 상태를 보고하는지 확인한다.
2. 결제 화면이 테스트 안내가 아닌 라이브 결제 안내와 승인된 결제수단 흐름으로 연결되는지 확인한다.
3. 실제 승인은 수행하지 않고 결제창 진입까지만 기술적으로 확인한다.
4. 이후 실제 결제·취소 검증은 운영자가 직접 진행한다.
